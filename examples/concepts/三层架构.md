# 三层架构

[[LLM Wiki]] 分三层，所有权清晰：

| 层 | 是什么 | 谁拥有 |
|---|---|---|
| **Raw sources** | 策展的源文档（文章、论文、图片、数据）。**不可变**——LLM 只读不改 | 人。这是 source of truth |
| **The wiki** | LLM 生成的 markdown 目录（摘要、实体页、概念页、对比、综述）。创建、更新、维护交叉引用、保持一致 | LLM 完全拥有。人读，LLM 写 |
| **The schema** | 一份配置文档，告诉 LLM wiki 怎么组织、约定是什么、各操作遵循什么工作流 | 人 + LLM 共同演进 |

## schema 层是关键

schema 是让 LLM 成为**有纪律的 wiki 维护者**而非通用聊天机器人的那份配置。Claude Code 里叫 `CLAUDE.md`，Codex 里叫 `AGENTS.md`。它定义目录用途、页面约定、以及 ingest / query / lint（见 [[三个操作]]）的具体流程。人和 LLM 随时间共同演进它——约定变了才改。

> 本 vault 的 schema 就是 `~/Wiki-Vault/AGENTS.md`，它把这套抽象模式实例化成了具体约定。

常见叫法：raw / wiki / schema 三层、源-wiki-规范三层、不可变源层、LLM 拥有的 wiki 层、配置文件层、CLAUDE.md / AGENTS.md。
