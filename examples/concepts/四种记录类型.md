# 四种记录类型

[[AWS Agent Registry]] 支持编目四种记录类型：

- **MCP**——[[Model Context Protocol]] server，及其工具、资源、prompts。
- **Agent**——[[Agent2Agent]]（A2A）agent card，定义 agent 及其技能。
- **Skill**——agent 技能定义（markdown 文件）及关联的代码/包。
- **Custom**——自定义描述符，必须是合法 JSON。

这四类都以记录形式进入 registry，走同一套[[记录生命周期]]。

常见叫法：四种记录类型、record types、MCP/Agent/Skill/Custom、可编目资源类型、注册资源类型、四类记录。
