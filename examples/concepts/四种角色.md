# 四种角色

[[AWS Agent Registry]] 围绕四种用户角色设计，覆盖从设护栏到消费能力的全链路：

- **Admins（管理员）**——搭建 registry、配置护栏、建立 agentic 发现与治理的流程。
- **Publishers（发布者）**——构建 agent、工具、技能并开放更广发现；可以是开发者，也可以是非技术人员。
- **Consumers（消费者）**——发现并使用组织内已批准可用的 agentic 能力；可以是开发者、业务用户或自主 agent。
- **Curators（策展者）**——人在环审阅者，按内部业务需求（如财务、安全、合规 PoC）批准或拒绝资源，管理生命周期决策。

## 与其他机制的对应

角色分别对应[[两个平面]]（Admin 用 Governance Plane，Consumer 用 Discovery Plane）并驱动[[记录生命周期]]的状态转换（Publisher 创建/提交，Approver 批准/拒绝，Curator 弃用）。

常见叫法：四种角色、四类用户、personas、Admins/Publishers/Consumers/Curators、管理员/发布者/消费者/策展者、人在环审阅者。
