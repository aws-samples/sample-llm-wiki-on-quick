# 记录生命周期

[[AWS Agent Registry]] 里每条记录走一套受治理的状态转换。

## 状态与转换

1. **DRAFT**——Publisher 创建新记录（或更新已有记录）时进入。
2. **PENDING_APPROVAL**——Publisher 提交草稿审批后进入。
3. **APPROVED / REJECTED**——Approver 审阅工作流结果后批准（→ APPROVED）或拒绝（→ REJECTED）。若 `auto_approve` 标志为 true 则自动进入 APPROVED。
4. **退回 DRAFT（可选环）**——记录在 PENDING_APPROVAL 或 APPROVED 状态时，Publisher 若更新它，会退回 DRAFT，重启提交流程。
5. **DEPRECATED**——Curator 在记录不再需要时随时可弃用，转入 DEPRECATED。

## 谁驱动

状态转换由[[四种角色]]分工驱动：Publisher 创建/提交/更新，Approver 批准/拒绝，Curator 弃用。审批流本身由 Admin 配置（Registry 只提供 hook），Amazon EventBridge 在记录进入 pending 后触发事件路由到审批工作流，AWS CloudTrail 记录全部操作审计。

常见叫法：记录生命周期、状态转换、state transitions、审批状态机、DRAFT/PENDING_APPROVAL/APPROVED/REJECTED/DEPRECATED、草稿到批准流程、生命周期状态。
