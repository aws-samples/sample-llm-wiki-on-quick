# Memex

Vannevar Bush 在 1945 年设想的一种个人知识存储装置：私人、主动策展，文档之间以**关联性的 trail（关联轨迹）**相连——文档间的连接与文档本身同样有价值。

## 与 LLM Wiki 的关系

原文指出 [[LLM Wiki]] 在精神上关联 Memex。Bush 的愿景更接近 LLM Wiki，而非 web 后来的样子：**私密、主动策展、连接即价值**。而 Bush 没能解决的部分是「谁来做维护」——LLM 正好处理了那部分（见 [[LLM Wiki]] 里「维护成本趋近于零」的论点）。
