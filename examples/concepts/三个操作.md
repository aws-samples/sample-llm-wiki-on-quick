# 三个操作

[[LLM Wiki]] 靠三个操作维护。以下是模式层面的描述（本 vault 的具体流程见 `AGENTS.md`）。

## Ingest——消化新素材

把新素材放进 raw 集合，让 LLM 处理。示例流程：读源 → 与人讨论要点 → 写摘要页 → 更新 index → 更新相关实体/概念页 → 追加 log。**一份素材可能牵动 10-15 页。** 可以一次一份并保持参与，也可以少监督地批量 ingest。

## Query——回答问题

向 wiki 提问。LLM 检索相关页、读它们、**带引用**综合出答案。答案形式随问题而定：markdown 页、对比表、幻灯片、图表、canvas。关键洞见：**好答案可以回填成 wiki 新页**——一个对比、一份分析、一处发现的关联不该消失在聊天记录里，回填后探索也像素材一样复利。

## Lint——体检

定期健康检查，找：页间矛盾、被新素材取代的过期说法、无入链的孤儿页、被提到却没有自己页面的重要概念、缺失的交叉引用、可靠一次联网搜索补上的数据缺口。也用来产出新的待研究问题和值得找的新素材。

常见叫法：ingest / query / lint、消化/查询/体检、摄入-提问-检查、三个操作、素材消化、回答并归档、wiki 体检、健康检查。
