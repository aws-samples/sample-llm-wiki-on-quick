# AgentCore Browser

[[AgentCore 服务簇]]中的**内置工具**之一：快速、安全的云端浏览器运行时，让 AI agent 在全托管环境里与 web 应用交互、填表、导航网站、抽取信息。兼容任意基础模型及 Playwright、BrowserUse 等浏览器自动化框架。

它是 agent 可用的两个内置工具之一（另一个是 [[AgentCore Code Interpreter]]），可经 [[AgentCore Harness]] 或 [[AgentCore Gateway]] 提供给 agent。

> 据总览页一段描述建页，会话隔离与并发模型待专门素材充实。

常见叫法：AgentCore Browser、云端浏览器、浏览器运行时、web 自动化、agent 浏览器、browser tool。
