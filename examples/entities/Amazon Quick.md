# Amazon Quick

AWS 面向业务用户和知识工作者的产品界面。本 vault 目前只从 [[AWS Agent Registry (AWS Blog)]] 一处素材了解其与 registry 的集成面。

## 在本素材里的角色

Quick 管理员把租户连接到一个或多个 [[AWS Agent Registry]] 后：

- 所有**已批准**的 agent、[[Model Context Protocol]] server、技能出现在 Quick 的 **Integrations 页**。
- 企业版用户可浏览/搜索全目录、看工具描述与能力、为租户启用特定 agent、分享给团队。
- 终端用户通过 **Quick Chat、Automations、Flows、Deep Research** 访问这些 agent。
- 价值：组织不必在 Quick 里重建别处已有的能力——单一受治理目录同时供开发者和业务用户使用。
